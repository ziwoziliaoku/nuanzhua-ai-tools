# 暖爪咖啡 WARM PAW · AI 内容生产与素材整理工具集

用 Python + 大模型 API 搭的一套小工具，解决两件每天都要重复的事：把一杯新品做成全套文案和出图提示词；把堆在下载文件夹里几百个素材分好类、清掉重复。

这是我 2026 年从内容运营转向 AI 应用开发的练习项目，从第一行 `print` 迭代到现在。

---

## 解决的两个问题

**问题一：新品文案写不过来**

出一杯新饮品，要重复四件事：想卖点、写文案、写生图提示词、起平台标题。纯手工做一次半小时，而且状态不好时质量飘。现在输入产品名，几十秒出全套，批量跑时一条三十秒。

**问题二：素材越攒越乱**

一年下来下载文件夹里 452 个文件、390 张图，同一份文件重复下载了好几次，找一张图要翻半天。现在一条命令分流到 12 个类别目录，再用文件指纹把真正重复的挑出来。

## 三条使用线

### 一、内容生产（`11-copywriter-v4.py`）

双击 `run-batch.bat`，或命令行：

```powershell
python 11-copywriter-v4.py
```

菜单里选 1 批量生成、选 2 查历史。输入季节、产品名、风格，结果自动存进 `批量生成结果/`，同时记一笔到 `历史记录.csv`。

五种风格：极简风 / 治愈系 / 复古风 / 高级感 / 国风。要加新风格，在 `STYLE_TEMPLATES` 里加一行就行。

### 二、素材整理（`12-asset-organizer.py`）

三种模式，从最安全的一种开始：

```powershell
# 第一步：体检，只统计不动文件
python 12-asset-organizer.py --folder "C:\Users\wjy\Downloads" --mode scan

# 第二步：出计划，算出每个文件该去哪，写成清单，还是不动文件
python 12-asset-organizer.py --folder "C:\Users\wjy\Downloads" --mode plan

# 第三步：执行。必须手输 YES 才会动
python 12-asset-organizer.py --folder "C:\Users\wjy\Downloads" --mode apply
```

执行后文件会进 `_整理结果/` 下的分类目录，例如 `01-海报`、`05-图片-按月/2026-09`、`08-视频`。每一次移动都记进 `搬迁日志.csv`，随时能照着日志搬回去。

### 三、重复清理（`13-find-duplicates.py`）

```powershell
# 只分析，不动文件
python 13-find-duplicates.py --folder "C:\Users\wjy\Downloads\_整理结果\00-待清理-重复"

# 分析并把多余的份搬到指定目录（不删除）
python 13-find-duplicates.py --folder "..." --move-to "C:\Users\wjy\Downloads\_重复待清理"
```

判断分两级：先比文件大小，大小不同直接排除；大小相同的再算 MD5 指纹，指纹一样才是同一份内容。

## 真实效果

| 场景 | 手工做 | 用工具 |
|---|---|---|
| 一条新品文案（含提示词、标题） | 约 30 分钟 | 约 30 秒 |
| 452 个素材文件分类 | 没做过，估计半天以上 | 执行约 10 秒 |
| 63 个疑似重复判定 | 逐个打开比对，容易看错 | 约 15 秒出结果 |
| 清理后回收的空间 | — | 55.47 MB，误删 0 个 |

素材那一栏的「半天以上」是估算，没有实测；其余数字都来自真实运行记录。

有一组数字值得单独记下来：63 个疑似重复里，按内容判断只有 9 组是真的，剩下 15 组只是「名字长得像」。比如 10 份 `1_每日销售表格.pdf` 体积从 90.6 KB 到 127.9 KB 各不相同，按文件名判断会全部当成重复删掉。

## 安全设计

写这类会动文件的工具，四道闸必须留着：

1. **默认只读**。不带执行参数就只统计，绝不动文件。
2. **执行前要人确认**。必须手输大写 `YES`，敲错就取消。
3. **可回滚**。每次移动都写日志，记录原路径和新路径。
4. **不覆盖、不整组清空**。目标位置有同名文件自动加序号；判重时每组永远保留一份。

还有一条跟安全无关但更贵：**密钥不写进代码**。

```powershell
setx ARK_API_KEY "你的密钥"
setx ARK_MODEL "你的模型接入点ID"
```

脚本从环境变量读。密钥写进代码，仓库一公开就等于把钥匙挂到网上。
