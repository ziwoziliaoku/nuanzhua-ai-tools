# 暖爪咖啡 WARM PAW · AI 内容生产工具集

用 Python + 大模型 API 搭的一套咖啡品牌内容自动化工具，把「卖什么 → 文案 → 出图提示词 → 平台标题」这条链路压缩到几十秒。

这是我 2026 年转型 AI 应用开发方向的练习项目，从第 1 行 Python 代码迭代到当前版本。

---

## 这个工具解决什么问题

做咖啡品牌内容，每个新品都要重复四件事：想卖点、写文案、写生图提示词、起平台标题。
纯手工做一次要半小时，而且质量不稳定。

这套工具把它变成：输入产品名 → 自动生成全套。批量跑时 30 秒一个产品。

## 工具进化史（01 → 09）

| 脚本 | 版本 | 学到的东西 |
|---|---|---|
| `01-hello-nuanzhua.py` | 第一行代码 | print、变量 |
| `02-hot-cocoa.py` / `02-互动热可可.py` | 第一次交互 | input、if-elif-else |
| `03-three-cases.py` | 三款产品 | 列表、for 循环 |
| `04-copywriter.py` | 文案生成器 v1 | 字符串拼接、格式化 |
| `05-copywriter-random.py` | 加随机性 | random 模块 |
| `06-ai-copywriter.py` | **首次调大模型** | API 调用、prompt 设计 |
| `07-ai-copywriter-save.py` | 自动保存 | 文件写入、时间戳 |
| `08-poster-prompt.py` / `-batch.py` | 海报提示词生成 | 多轮 API、批量处理、CSV |
| `09-copywriter-tool.py` | **工具 v2（当前主力）** | 函数化重构、模板库、异常重试 |

### 09 的关键升级

- **函数化**：`build_prompt()` / `call_ai()` / `save_result()` / `write_csv()` / `main()` 职责分离
- **风格模板库**：极简风 / 治愈系 / 复古风 / 高级感 / 国风，一行配置即可扩展
- **API 自动重试**：调用失败自动重试，不再因为一次网络抖动就整批失败

## 运行方式

### 1. 环境

- Python 3.12+
- 依赖：`pip install openai`

### 2. 配置 API Key（重要）

脚本从**环境变量**读取密钥，不写在代码里：

```powershell
# Windows 永久生效
setx ARK_API_KEY "你的密钥"
setx ARK_MODEL "你的模型接入点ID"
```

> 为什么这么做：密钥写进代码，一旦仓库公开就等于把钥匙挂到网上。这是这个项目里我学到的最重要的一课。

### 3. 使用

双击 `run-batch.bat` 启动，或命令行：

```bash
python 09-copywriter-tool.py
```

按提示输入季节、产品、风格，结果自动保存到 `批量生成结果/`。
